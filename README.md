# 27 — Aplicación personal

Aplicación web personal para organizar hábitos, formación, estudios académicos y experiencias puntuales, manteniendo separados sus registros y estadísticas.

El proyecto debe priorizar un registro sencillo, datos persistentes y una experiencia útil sin generar presión ni obligaciones innecesarias.

## Especificación

Los requisitos completos del proyecto están en [`docs/REQUISITOS.md`](docs/REQUISITOS.md).

## Estado

Este repositorio contiene la especificación inicial del proyecto. La aplicación todavía no está implementada.
